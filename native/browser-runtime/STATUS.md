## Limits and remaining delivery

Accepted native execution is macOS arm64. Windows and x64 native builds are not established; unsupported source encryption fails explicitly. Real Chrome directory discovery, optional index metadata and real history import are accepted after the user changed system access policy (1178). Real encrypted Cookie/password acceptance did not return an import receipt before its ten-minute deadline, and its owned application and temporary target were closed (1191). An earlier owned-process sample shows the native source reader waiting in SecItemCopyMatching (1181); no credential data was inspected. Normal system Keychain authorization and a completed real import remain unaccepted. Synthetic import does not replace that acceptance. Copy failures now preserve the original operation, database/WAL/SHM part, file error and errno without assuming that all failures indicate missing source permissions. The native CSV picker reached its real dialog but selection was refused by the UI focus guard; no picker success is claimed. Legacy Electron profile files are retained without unverified internal database copying.

The source-import runtime receipt, complete bundle tree and packager ZIP pass verification (1029). A local unsigned package passes resource verification with an explicitly selected existing engine artifact; no new engine build or release is implied (1031). Development preparation passed (878), and the final native runtime is consumed by a verified local application package (910).
