## Limits and remaining delivery

Real database import failed at the copy stage with EPERM, and system Keychain authorization remains untested; synthetic import does not establish those acceptances. Copy failures now preserve the original operation, database/WAL/SHM part, file error and errno without assuming that all failures indicate missing source permissions. The native CSV picker reached its real dialog but selection was refused by the UI focus guard; no picker success is claimed. Legacy Electron profile files are retained without unverified internal database copying.
